# Tarangini Workflow Suite 1.2.1

## Internal Update Activation Release

- Activates the first online update-feed release for systems already running
  version 1.2.0 or later.
- Keeps the existing safe update behavior: check automatically, download and
  restart only when the owner or user chooses, and block client installation
  while offline work is pending or conflicted.
- Contains the verified 1.2.0 application feature set with no database schema,
  accounting, job-workflow, or customer-data changes.

## Internal Distribution Notice

This release is unsigned while the organization defers Authenticode signing.
It is for controlled internal deployment only. Windows may show an unknown
publisher warning. Do not publish an unsigned release to external customers.
