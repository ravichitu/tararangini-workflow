# Tarangini Workflow Suite 1.2.2

## Greeting Module

- Shows Good morning, Good afternoon, or Good evening after a successful login.
- Adds a concise time-aware greeting to owner and operator dashboards.
- Shows a brief Signing off flash before logout while the session is secured.
- Keeps Main System tray mode, customer portal availability, accounting data, and job data unchanged.

## Update Safety

- The feature is fully local to the interface and does not create new database records or transmit personal data.
- Installer signing remains intentionally deferred for internal-use testing.
